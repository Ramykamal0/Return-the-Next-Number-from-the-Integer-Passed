# Return the Next Number from the Integer Passed

## 📝 Description
A simple C# console application that takes an integer as input and returns the next number by incrementing it by 1.

## 🛠️ Language & Tools
- Language: C#
- IDE: Visual Studio
- Framework: .NET

## 🚀 How to Run
1. Clone the repository
2. Open `Return the Next Number from the Integer Passed.slnx` in Visual Studio
3. Press `F5` to run

## 📌 Example

**Input:**
```text
5
```

**Output:**
```text
6
```
